# AmneziaWG проекты

Сборка решений для AmneziaWG VPN с разными топологиями.

## Какой вариант выбрать

| Вариант | AWG-машина | Маршрутизация трафика | Когда брать |
|---------|-----------|-----------------------|-------------|
| [**awg**](./awg/) | За NAT (под роутером) | Делает роутер (MikroTik mangle и т.п.) | У тебя уже есть роутер с правилами, нужен только AWG-сервер |
| [**awg-ipip-gre**](./awg-ipip-gre/) | В облаке с публичным IPv4 | Сам сервер через IPIP/GRE к exit-нодам | AWG в облаке, выход в интернет нужен через другую страну |

Оба варианта:
- Веб-панель `amnezia-wg-easy` (форк w0rng) **на хосте, без Docker**
- Подсеть AmneziaWG — `/24` (ограничение веб-панели)
- Поддержка **Ubuntu 22.04 / 24.04**

Подробности — в README каждого подкаталога.
